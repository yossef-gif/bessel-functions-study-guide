Chapter 1: Bessel's Differential Equation

The Bessel Equation

x2y″ + xy′ + (x2 - ν2)y = 0 where ν is a real, non-negative parameter (the order)

This is one of the most important second-order linear ODEs in mathematical physics. It appears when solving Laplace, Helmholtz, and wave equations in cylindrical or spherical coordinates.

General Solution

y = A·Jν(x) + B·J-ν(x) where A, B are arbitrary constants
When ν is an integer, J-ν and Jν are linearly dependent, so a second solution (Neumann function Yν) is needed instead.

Series Definition (Frobenius Solution)

Jν(x) = ∑r=0∞ [(-1)r / (r! · Γ(ν+r+1))] · (x/2)2r+ν where: - r! is the factorial - Γ(ν+r+1) is the Gamma function - The series converges for all x ≥ 0

Special Values

Function Value at x = 0 Reason
J0(0) 1 The r=0 term gives (x/2)0/(0!·Γ(1)) = 1
Jν(0) for ν > 0 0 Every term contains a positive power of x

Chapter 2: Recurrence Relations

The Six Fundamental Relations

# Relation Type
1 d/dx[xν Jν(x)] = xν Jν-1(x) Derivative
2 d/dx[x-ν Jν(x)] = -x-ν Jν+1(x) Derivative
3 J'ν(x) = Jν-1(x) - (ν/x)·Jν(x) From Relation 1
4 J'ν(x) = (ν/x)·Jν(x) - Jν+1(x) From Relation 2
5 ∫ xν Jν-1(x) dx = xν Jν(x) + C Integral
6 ∫ x-ν Jν+1(x) dx = -x-ν Jν(x) + C Integral

Key Observation

Adding Relations 3 and 4 eliminates J'ν and gives a useful recurrence relation for the Bessel functions themselves. Subtracting them gives another important form used for computing higher-order functions.

Chapter 3: Half-Integer Bessel Functions

Elementary Forms

For half-integer orders, Bessel functions reduce to elementary trigonometric functions:

J1/2(x) = √(2/(π·x)) · sin(x)
J-1/2(x) = √(2/(π·x)) · cos(x)

These results are particularly important because they show that some Bessel functions are elementary functions. Higher half-integer orders can be expressed in terms of trigonometric and rational functions.

Higher Half-Integer Example

J3/2(x) = √(2/(π·x)) · [sin(x)/x - cos(x)]

Chapter 4: Integration Examples

General Strategy

To integrate ∫ xm Jn(x) dx, use the following approach:

  • Rewrite xm as xn · xm-n
  • Use integration by parts with the integral relations
  • Repeatedly reduce the power until matching a fundamental formula

Example 1: ∫ x5 J2(x) dx

Solution: x5J3(x) - 2x4J4(x) + C Steps: 1. Rewrite: ∫ x5 J2(x) dx = ∫ x2 · (x3 J2) dx 2. Integration by parts with ∫ x3J2 dx = x3J3(x) 3. Result: x5J3(x) - 2∫ x4J3(x) dx 4. Apply Relation 5 again: 2∫ x4J3 dx = 2x4J4(x)

Example 2: ∫ x6 J3(x) dx

Solution: x6J4(x) - 2x5J5(x) + C

Example 3: ∫ J4(x)/x dx

Solution: -x-1J3(x) - 2x-2J2(x) + C Uses Relation 6 for negative powers

Chapter 5: Expressing Higher Orders in J0 and J1

Recurrence Formula

Jν+1(x) = (2ν/x)·Jν(x) - Jν-1(x) This means any integer-order Bessel function can be expressed using only J0(x) and J1(x)

Examples

Function Expression
J0(x) Base function
J1(x) Base function
J2(x) (2/x)·J1(x) - J0(x)
J3(x) [(8-x2)/x2]·J1(x) - (4/x)·J0(x)
J4(x) [(48-12x2)/x3]·J1(x) - [(8-x2)/x2]·J0(x)

Chapter 6: Product Identity Proof

The Identity to Prove

d/dx[x·J5(x)·J6(x)] = x·[J52(x) - J62(x)]

Key Insight

Factor x as either x = x5 · x-5 or x = x6 · x-6. This allows us to apply Relations 1 and 2 separately to each factor, leading to a clean cancellation.

Proof Sketch

  • Step 1: Rewrite as x-5J5(x) · x6J6(x)
  • Step 2: Apply product rule
  • Step 3: Use Relation 1 with ν=6: d/dx[x6J6] = x6J5
  • Step 4: Use Relation 2 with ν=5: d/dx[x-5J5] = -x-5J6
  • Step 5: Substitute and simplify to get x(J52 - J62)
